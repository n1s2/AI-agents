# FLOOWBOX - Product Launch Campaign Orchestrator

One webhook call → complete multi-channel launch campaign. Email, LinkedIn, Twitter thread, Product Hunt, WhatsApp, landing page copy, CTAs, and a launch day checklist — all generated and ready to review.

## What it does

Send product details via webhook. GPT-4o generates the complete launch campaign in one shot across every channel. Everything saves to a Notion launch hub. Slack preview of the key assets.

## Tools Used
- n8n, OpenAI GPT-4o, Notion, Slack

## Output
Launch email + LinkedIn + Twitter thread (3 tweets) + Product Hunt tagline + description + WhatsApp broadcast + landing page H1 + subhead + 3 CTA variants + launch checklist.

## Setup
1. OpenAI API key
2. Notion DB + Slack Bot + #marketing channel
