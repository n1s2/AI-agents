# FLOOWBOX - Social Proof Aggregator

Testimonials sitting in a spreadsheet don't convert. This workflow collects, polishes, maps to use cases, and surfaces the best quotes weekly — so social proof is always fresh and strategically placed.

## What it does

Weekly scan of G2, Capterra, and Trustpilot for new reviews, plus pulls raw testimonials from a Google Sheet. GPT-4o polishes each quote, identifies what use case it proves, and recommends where to use it. Flags which product benefits still have no testimonial coverage.

## Tools Used
- n8n, Perplexity AI, OpenAI GPT-4o, Google Sheets, Notion, Slack

## Setup
1. Perplexity API key, OpenAI API key
2. Google Sheets with raw testimonials
3. Notion DB + Slack Bot + #marketing channel
