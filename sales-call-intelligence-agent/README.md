# FLOOWBOX - Sales Call Intelligence Agent

Post any sales call transcript and get: pain points extracted, objections analyzed, deal scored, CRM updated, and a personalized follow-up email drafted — automatically.

## What it does

Transcript arrives via webhook. GPT-4o analyzes the full conversation — deal stage, buying signals, objections and how they were handled, red flags, and agreed next steps. Auto-creates a CRM record in Airtable, drafts a follow-up email, and posts a summary to Slack.

## Tools Used
- n8n, OpenAI GPT-4o, Airtable, SMTP, Slack

## Setup
1. OpenAI API key
2. Airtable Deals table
3. SMTP credentials
4. Slack Bot + #sales channel
