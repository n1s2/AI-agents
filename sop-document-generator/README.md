# FLOOWBOX - SOP Document Generator

Describe any business process and get a complete, structured Standard Operating Procedure document — with steps, roles, troubleshooting, and quality checkpoints.

## What it does

Send a process name and description via webhook. GPT-4o generates a professional SOP with purpose, scope, roles and responsibilities, numbered steps with checkpoints, tools needed, and a troubleshooting guide. Saves to Notion as a draft.

## Tools Used
- n8n, OpenAI GPT-4o, Notion

## Use cases
New employee onboarding, compliance documentation, process handoffs, client deliverable packages.

## Setup
1. OpenAI API key
2. Notion integration + DB ID
